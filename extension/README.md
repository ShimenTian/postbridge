# 文桥长文导入助手（实验版）

用于一次导入正文及多张代码图片，减少逐张复制。代码图片由文桥现有公众号渲染器生成。

## 安装一次

1. 在 Chrome 扩展程序管理页开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目的 `extension` 文件夹。
3. 将“文桥长文导入助手”固定到工具栏。

扩展只申请 `activeTab` 和 `scripting`：点击图标后在当前的小红书或抖音创作页面运行，无常驻网页访问权限。图片交给对应平台自己的上传逻辑处理，不经过文桥服务器。

## 每篇文章

1. 文桥中选择“小红书长文”或“抖音文章”，点击“导出文章包”。
2. 打开对应平台的长文正文编辑器，点击导入助手图标。
3. 选择下载的 `.postbridge.json` 文件，点击“开始导入”。
4. 等待图片依次上传完成，检查正文、填写标题，再自行发布。

已有正文时默认阻止导入；勾选“追加”才会写入末尾。导入过程中请保留页面，避免切换编辑器。点击停止会等待当前图片完成，再将剩余代码保留为文字。

## 当前验证范围与限制

文章包导出已通过三段代码的真实浏览器验证。小红书 0.1.1 已在 Chrome 实测：三张代码图片各上传一次、按段落顺序插入、标记清理完成、图片加载成功，原有正文保持完整。抖音导入效果已由用户反馈确认，本次保持其上传路径。当前仍标为实验版。助手依赖平台当前 Tiptap 编辑器与粘贴上传接口，平台更新可能影响兼容性。

每包最多 100 张图片、32 MB。远程配图需要允许浏览器跨站读取；读取失败会停止导出并提示。图片上传超时会停止后续操作并保留位置标记，不会自动重试，以免产生重复图片；请等待平台处理并核对正文后再操作。标题、封面和发布由用户完成。

## 更新到 0.1.1

在 Chrome 扩展程序管理页找到“文桥长文导入助手”，点击重新加载。关闭旧的导入面板后重新点击助手图标即可使用更新。旧稿中的残留标记与错位图片不会自动修复；建议在空白长文稿中重新导入原文章包，核对完成后再处理旧稿。文章包无需重新导出。
